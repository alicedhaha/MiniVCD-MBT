# Mooncakes uniqueness check

Checked on 2026-08-14 at [mooncakes.io](https://mooncakes.io).

Search terms: `vcd`, `value change dump`, `verilog waveform`, `waveform parser`,
`digital waveform`, `rtl waveform`, and `logic waveform`.

No MoonBit package implementing a substantially similar VCD parser or viewer
was found. Results related to waveform generation or processing were audio/DSP
packages (for example oscillator/demo waveform code), so they were not treated
as duplicates. Generic parsers, trace/log tools, and ordinary time-series
packages were also outside this project's scope.

Conclusion: no collision was found, so MiniVCD-MBT development proceeded.
